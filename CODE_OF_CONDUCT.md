# Code of conduct

## Short version

Be decent. Assume good faith. No harassment, no spam, no malware.

## Expected behaviour

- talk about the code, not about the person;
- give feedback that helps the project;
- never post real passwords, tokens or personal data;
- respect that this tool is used for security work.

## Not accepted

- offensive or discriminatory remarks;
- publishing other people's passwords or private logs;
- deliberately weakening the generator or adding data exfiltration;
- spamming issues and pull requests.

## Enforcement

Report problems to `pastypew@gmail.com`. Maintainers may edit or remove
issues, comments and code that break these rules, and may ban accounts that
keep misbehaving.
